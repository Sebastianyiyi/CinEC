# CinEC 🎬

Plataforma web para la compra de boletos de cine. Permite explorar la cartelera, ver detalles de películas, seleccionar asientos y comprar entradas.

## Tecnologías

- React 18 + TypeScript
- Vite
- Tailwind CSS v3
- shadcn/ui
- React Router v6
- TanStack Query v5
- Framer Motion

## Instalación

```bash
npm install
npm run dev
```

## Ramas

- `main` → producción
- `develop` → integración
- `feature/*` → funcionalidades
