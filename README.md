# CinEC - Sistema de Reserva de Entradas de Cine

CinEC es una aplicación web desarrollada con React y Vite que simula un sistema de selección y reserva de asientos para funciones de cine.  
El proyecto permite visualizar películas disponibles, seleccionar funciones y elegir asientos dentro de una sala de cine mediante una interfaz interactiva.

Este proyecto fue desarrollado con fines académicos y está diseñado para ejecutarse únicamente en un entorno de desarrollo local.

---

## Comenzando 🚀

Estas instrucciones te permitirán obtener una copia del proyecto en funcionamiento en tu máquina local para propósitos de desarrollo y pruebas.

Actualmente el proyecto **no cuenta con despliegue en producción**, por lo que solo se ejecuta en un entorno local.

---

## Pre-requisitos 📋

Para ejecutar este proyecto necesitas tener instalado:

- Node.js (versión 18 o superior recomendada)
- npm o bun como gestor de paquetes
- Git

Puedes verificar tus versiones con:
```
node -v
npm -v
```

---

## Instalación 🔧

Sigue estos pasos para ejecutar el proyecto en tu máquina local.

### 1. Clonar el repositorio
```
git clone https://github.com/Sebastianyiyi/CinEC.git
```

### 2. Entrar en la carpeta del proyecto
```
cd CinEC
```

### 3. Instalar dependencias
```
npm install
```

o si usas bun:
```
bun install
```

### 4. Ejecutar el servidor de desarrollo
```
npm run dev
```

Esto iniciará el servidor de desarrollo de Vite.

### 5. Abrir la aplicación

Abre tu navegador y entra a:
```
http://localhost:5173
```

## Construido con 🛠️

Las principales tecnologías utilizadas en este proyecto son:

- React – Biblioteca para construir interfaces de usuario
- Vite – Herramienta de desarrollo y bundler
- TypeScript – Superset tipado de JavaScript
- TailwindCSS – Framework de estilos utilitario
- Radix UI – Componentes accesibles para interfaces modernas
- React Router – Manejo de rutas en la aplicación
- React Hook Form – Manejo de formularios
- Vitest – Framework de pruebas
