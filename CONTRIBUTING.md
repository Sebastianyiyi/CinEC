# Contributing

Gracias por tu interés en contribuir a **CinEC** 🎬

Este proyecto fue desarrollado con fines académicos y cualquier mejora, corrección de errores o sugerencia es bienvenida. Para mantener un flujo de trabajo organizado, por favor sigue las siguientes recomendaciones antes de contribuir.

---

# Cómo contribuir

Si deseas proponer una mejora, nueva funcionalidad o corrección de errores:

1. Revisa primero los **Issues existentes** para evitar duplicados.
2. Si el cambio es grande o modifica funcionalidades importantes, abre primero un **Issue** explicando tu propuesta.
3. Realiza los cambios en un **fork del repositorio** o en una **rama nueva**.

---

# Proceso de Pull Request

Cuando envíes un Pull Request asegúrate de:

1. Crear una nueva rama basada en `main`.

```
git checkout -b feature/nombre-de-tu-cambio
```

2. Mantener commits claros y descriptivos.

Ejemplo:

```
feat: agregar selección de asientos
fix: corregir error en navegación entre funciones
```

3. Asegurarte de que el proyecto siga ejecutándose correctamente en local:

```
npm install
npm run dev
```

4. Si agregas funcionalidades nuevas o cambios importantes, actualiza el **README.md** si es necesario.

5. Finalmente envía el **Pull Request** y describe claramente:

   * qué cambio realizaste
   * por qué era necesario
   * qué parte del sistema afecta

---

# Buenas prácticas de código

Para mantener consistencia en el proyecto:

* Mantén una estructura clara de componentes.
* Usa **TypeScript correctamente tipado** cuando sea posible.
* Sigue el estilo de código existente del proyecto.
* Evita subir archivos innecesarios o dependencias compiladas.

---

# Código de Conducta

Este proyecto busca mantener un ambiente respetuoso y colaborativo.

Esperamos que todos los participantes:

* Usen un lenguaje respetuoso e inclusivo
* Acepten críticas constructivas
* Colaboren de forma positiva con el equipo

No se tolerarán comportamientos como:

* insultos o ataques personales
* acoso o discriminación
* publicación de información privada de otros colaboradores

Los mantenedores del proyecto podrán rechazar contribuciones o moderar interacciones que no respeten estas normas.
